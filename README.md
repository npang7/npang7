## 🚀 Featured Projects

### 👣 StepWise — Asynchronous Gait Analysis Service

🔗 [Source](https://github.com/npang7/stepwise-gait-analysis)

A FastAPI service that turns pressure-sensor and IMU recordings into gait metrics and downloadable reports, with isolated workers, restart recovery, and an optimized analysis pipeline.

### ⚡ Real-Time Analytics Dashboard · Collaborative Project

🔗 [Source](https://github.com/JiajunWang23/realtime-analytics-dashboard)

A collaborative analytics platform streaming Wikipedia events through Flask, Redis pub/sub, and PostgreSQL to a React dashboard over WebSockets, with indexed queries, rollups, and batched event delivery.

### ⚙️ Dynamic-Batching Inference Service

🔗 [Source](https://github.com/npang7/dynamic-batching-inference-service)

A FastAPI/PyTorch inference service with asynchronous batching, bounded admission, result caching, and Prometheus metrics, built to explore throughput–latency trade-offs.

### 🧩 Illinix — RISC-V Operating System

🔗 [Source]((https://github.com/npang7/riscv-os)


A Unix-like operating-system project covering Sv39 virtual memory, preemptive scheduling, system calls, device drivers, and an inode-based file system.

### 📄 PushResume · Internship Contributions

Contributions to an AI resume platform spanning parsing and suggestions, request quotas, job-data APIs, payments, and authentication.
